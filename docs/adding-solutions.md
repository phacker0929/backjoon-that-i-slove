# 풀이 추가 방법

## 직접 추가하기

새 풀이 폴더는 다음 형식을 사용합니다.

```text
solutions/{사이트}/{언어}/{문제번호}-{문제명}/
├── README.md
└── solution.{확장자}
```

문제명에는 Windows에서 사용할 수 없는 문자인 `\ / : * ? " < > |`를 넣지 않습니다. 공백은 하이픈으로 바꿉니다.

문제 README에는 다음 항목을 기록합니다.

- 원본 문제 링크
- 사용 언어
- 핵심 알고리즘 또는 자료 구조
- 시간·공간 복잡도
- 틀린 이유나 다시 확인할 내용

같은 언어로 다른 풀이를 추가할 때는 `solution-two-pointers.py`처럼 접근 방법을 파일명에 표시합니다.

## 백준허브를 사용할 때

GitHub 저장소 이름이 변경되었으므로 백준허브에서 `algorithm-practice` 저장소를 다시 연결했는지 확인합니다. 백준허브는 플랫폼별 또는 언어별 폴더 구성을 선택할 수 있지만, 이 저장소의 `solutions/사이트/언어/문제` 구조와 완전히 같지는 않을 수 있습니다.

자동 업로드 뒤 새로 생긴 최상위 폴더는 바로 삭제하지 않습니다. 풀이와 문제 README를 해당 문제 폴더로 옮기고 중복 여부를 확인한 뒤 정리합니다.

## 커밋 예시

```text
solve: 백준 1234 문제 Python 풀이 추가
docs: 1234 문제 복습 내용 추가
refactor: 알고리즘 풀이 폴더 정리
```
