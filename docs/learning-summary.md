# 학습 내용 정리

저장소에 남아 있는 풀이를 기준으로 확인한 알고리즘 학습 내용입니다. 제출 기록이 있는 문제와 로컬 풀이를 함께 분석했으며, 실제 학습 순서나 숙련도를 임의로 단정하지 않습니다.

## 기초 입출력과 조건문

1000, 10869번에서는 입력값을 정수로 바꾸고 사칙연산 결과를 출력합니다. 1330, 2480번에서는 여러 조건을 비교해 다른 결과를 선택합니다. 2525번은 분 단위 값을 시와 분으로 변환하면서 나눗셈과 나머지를 사용합니다.

## 반복문과 리스트

10818, 1546, 2439, 2750번에서는 반복 처리, 리스트, 최솟값·최댓값·정렬을 사용합니다. 같은 작업을 직접 반복하는 방법과 Python 내장 함수로 표현하는 방법을 비교할 수 있습니다.

## 문자열 처리

10171번은 역슬래시 같은 문자를 출력하는 방법을, 1032번은 여러 문자열의 같은 위치를 비교하는 방법을 다룹니다. 10988번은 슬라이싱으로 문자열을 뒤집고, 2743과 2744번은 길이와 대소문자를 처리합니다. 9012번은 문자열을 순서대로 읽으면서 괄호의 균형을 확인합니다.

## 자료 구조

10828번은 리스트 또는 배열을 스택으로 사용합니다. 18258번은 앞쪽 원소를 효율적으로 제거하기 위해 `collections.deque`를 사용합니다. 9012번은 괄호를 직접 저장하지 않고 현재 열린 괄호 수만 기록하는 방식으로 스택 문제를 단순화합니다.

## 탐색과 정렬

1920번은 데이터를 정렬한 뒤 이분 탐색으로 값의 존재 여부를 확인합니다. 3273번에는 집합을 이용한 풀이와 정렬 후 양쪽 포인터를 이동하는 풀이가 모두 있어 두 접근을 비교할 수 있습니다.

## 매개 변수 탐색

2343번과 프로그래머스 43238번은 정답이 될 수 있는 값의 범위를 이분 탐색합니다. 중간값이 조건을 만족하는지 검사하고, 가능하면 더 작은 값으로 범위를 줄이는 공통 구조가 나타납니다.

## 수학적 규칙

1009번은 거듭제곱의 마지막 자리가 일정한 주기로 반복된다는 성질을 사용합니다. 큰 지수를 그대로 계산하기보다 나머지와 주기를 이용하는 이유를 복습할 수 있습니다.

## 다음 복습 항목

- 각 풀이에 시간 복잡도와 공간 복잡도를 기록합니다.
- 로컬 풀이를 문제의 공식 예제 입력과 경계값으로 다시 실행합니다.
- 3273번의 집합 풀이와 두 포인터 풀이의 장단점을 비교합니다.
- 1920, 2343, 43238번의 이분 탐색에서 탐색 대상이 어떻게 다른지 설명합니다.
- 새 문제를 추가할 때 문제 폴더 README에 접근 방법과 틀린 이유를 짧게 기록합니다.

## 확인이 필요한 기존 풀이

- 2439번은 출력 횟수가 5로 고정되어 있어 입력값을 사용하는 형태인지 다시 확인해야 합니다.
- 1009번은 큰 지수 계산을 직접 수행하는 분기가 있어 효율을 다시 검토할 필요가 있습니다. 파일 안에 주기를 이용한 대안 코드가 주석으로 남아 있습니다.
- 10171번은 현재 출력은 가능하지만 역슬래시가 일반 문자열 안에 있어 Python 문법 검사에서 경고가 발생합니다. raw 문자열이나 역슬래시 이스케이프 방식으로 정리할 수 있습니다.
- 자동 채점 README가 없는 로컬 풀이들은 문법 검사와 간단한 예제 실행만으로 전체 정답 여부를 확정할 수 없습니다.
